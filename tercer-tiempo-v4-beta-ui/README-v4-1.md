# Tercer Tiempo V4.1 Beta UI

Mejora de interacción en la formación:

- reordenamiento de jugadores mediante arrastre en PC y celular;
- grip táctil/ratón visible junto a cada jugador;
- arquero fijo en la primera posición y editable desde su selector;
- flechas existentes conservadas como alternativa;
- soporte de teclado con ArrowUp/ArrowDown sobre el grip;
- corrección visual del equipo rojo en la cancha: izquierda/derecha se espeja fila por fila según el sentido de juego.

La corrección del espejo afecta sólo la representación visual compartida; no altera la alineación guardada ni los datos del grupo.
